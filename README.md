# TriggerBot — эксперименты с захватом и обработкой кадров

```
pip install -r requirements.txt
```

## Структура

```
src/
  win_cam.py            ThreadedCapture — захват экрана через wincam (DXGI, Windows)
  sources.py            ScreenSource / DemoSource / StaticScene (фон + окно + цель)
  processing/
    diff_blend.py       difference_blend(): |A - B|, усиление, порог, бинарная маска
    motion.py           MotionDetector: детекция движения под прицелом
  qt_utils.py           numpy <-> QImage, провайдер картинок для QML
apps/
  diff_blend/           отдельное приложение Difference Blend (Python + QML)
  motion_lab/           лаборатория детектора на статической картинке (Python + QML)
testing/
  benchmark.py          замер FPS захвата
  test_motion.py        тесты детектора (pytest)
```

## Difference Blend

```
python -m apps.diff_blend          # захват экрана (Windows)
python -m apps.diff_blend --demo   # синтетический источник, работает где угодно
```

Регион X/Y/W/H и FPS задаются сверху, «Старт» перезапускает захват.
Сравнение с предыдущим кадром (или с кадром N назад) либо с опорным снимком.
Усиление делает видимыми слабые изменения, порог отсекает шум.

## Motion Lab

```
python -m apps.motion_lab                 # процедурный фон
python -m apps.motion_lab screenshot.png  # свой скриншот как фон
python -m apps.motion_lab --auto          # сразу включить авто-проходы цели
```

* Синяя рамка — окно захвата, белый крест — прицел, жёлтый квадрат — зона детекции.
* Рамку можно тащить мышкой или двигать стрелками/WASD (Shift — быстрее). Это имитация движения камеры.
* «Проход цели» (Space) — силуэт пробегает через прицел. Цель можно таскать мышкой
  или загрузить свою (PNG с прозрачностью).
* Каждый выстрел проверяется: был ли прицел на непрозрачной части цели → «попал / мимо».
  Следы выстрелов остаются на сцене.
* «Покачивание камеры» и «Шум кадра» нужны, чтобы проверить, что детектор не стреляет
  от движения мышью и от шума сжатия.

### Как работает детектор (`src/processing/motion.py`)

1. Кадр → яркость → (опционально) уменьшение 2×/4× для подавления шума.
2. **Компенсация камеры**: фазовая корреляция (FFT) даёт кандидатов глобального сдвига.
   Выбирается тот, после которого медианная разница кадров минимальна. Камера — это то, что
   объясняет *большинство* пикселей, поэтому сама цель не принимается за поворот камеры.
3. `|кадр − выровненный предыдущий| > порог` → маска. Порог задаётся **чувствительностью**
   (100 → 4 уровня яркости, 0 → 84).
4. Если в центральной зоне изменилось ≥ `min_area` пикселей, это движение.
   Если после компенсации меняется ещё и большая часть кадра вокруг (`camera_limit`),
   кадр игнорируется.
5. Машина состояний:
   `ожидание → подтверждение (N кадров) → задержка (fire_delay_ms) → ВЫСТРЕЛ → кулдаун → ждём покоя`.

| Параметр | Если слишком реагирует | Если пропускает |
|---|---|---|
| Чувствительность | ↓ | ↑ |
| Мин. площадь в зоне | ↑ | ↓ (медленные цели дают узкую полосу изменений) |
| Подтверждение | ↑ (2–3 кадра) | 1 |
| Задержка выстрела | ↑ | 0 |
| Кулдаун | ↑ | ↓ |
| Уменьшение кадра | 2× при шуме | 1× для мелких целей |

Детектор не зависит от Qt и получает время снаружи:

```python
from src.processing import MotionConfig, MotionDetector

det = MotionDetector(MotionConfig(sensitivity=70, fire_delay_ms=30), on_fire=lambda t: ...)
result = det.process(frame_bgr, now_ms)   # result.fired, result.state, result.zone_ratio ...
```
